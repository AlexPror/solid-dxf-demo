SOLIDWORKS 2018 SP3 · надстройка «Пакет в цех»

Один перечень Excel — готовый комплект для лазера и цеха

Между выпуском КБ и запуском листового участка — сотни позиций: DXF на резку, чертежи развёрток, PDF-альбом, раскладка по толщине. До 8 проектов в месяц, в каждом 100–200 деталей. Сейчас это часы ручной рутины и риск, что ошибка всплывёт уже у станка.

Задача

Не «нажать кнопку DXF», а связать конструкторский комплект с производством: из одного перечня Excel получить согласованный пакет файлов для лазера, гибочного станка и архива — без потери позиций и без сюрпризов на станке.

Каждый пропущенный лист в перечне — потенциальный простой лазера или переделка на гибочном станке.

Масштаб

До 8 проектов в месяц × 100–200 позиций — тысячи артефактов (DXF, чертежи, страницы PDF). Ручной прогон превращается в постоянную нагрузку на отдел технологии.

Время и очередь

Лазер и гибочный станок ждут комплект. Срочный проект нельзя «доделать ночью по одной детали» — нужен цельный пакет за один проход, иначе узкое место сдвигается в цех.

Качество комплекта

Ошибки редко видны в Excel: пропущенная строка, не то исполнение из PDM, DXF не в папке толщины, нет чертежа модели. Итог — переделка, брак, неполный альбом.

Связка подразделений

КБ → технологическое бюро → лазер → гибочный станок. Плагин закрывает участок «перечень → папка лазер»: единые правила имён, структуры и оглавления PDF.

Сейчас (вручную)

  • Поиск моделей в PDM или папке — по каждой позиции
  • DXF и развёртки по одной детали, чертежи — отдельно
  • PDF и оглавление собирают вручную или частично
  • Раскладка по дате, толщине, проверка «всё ли на месте» — на глаз
  • Ориентир: 5–10 ч на проект 100–200 поз. (если часть _развертка.slddrw уже есть)

Демонстрация

Запись экрана на Яндекс.Диске (без VPN). Полный прогон: Excel → проверка → папка «лазер» → PDF-альбом.

Как это выглядит

Скриншоты с реального прогона — экран комплекта, папка «лазер», оглавление PDF.

Положите файлы preflight.png, folders.png, toc.png в папку img/ — плейсхолдеры заменятся автоматически.

Логика решения

Выбор не между «делать / не делать», а между способами закрыть одно узкое место — перечень Excel → папка «лазер».

  • Как сейчас — нагрузка на ТБ каждый проект (задача)
  • Ещё технолог — постоянный ФОТ, тот же ручной процесс
  • Готовый продукт — нет цепочки Excel → PDM → толщина → PDF под ваши правила
  • Интегратор — тот же класс задач, другая цена

Цех + лазер

PDM, чертежи развёрток, структура папок

Почему PDM обязателен

Без хранилища нельзя гарантировать версию и конфигурацию детали на лазере. Плагин не заменяет PDM — он берёт из хранилища правильные файлы. Результаты в PDM не сдаём (запись в PDM не выполняем).

Версия

Режем и кладём в альбом ту ревизию, что в хранилище.

Конфигурация

Исполнения -01, -02 — выбор на экране комплекта.

Только чтение

Поиск по шифру по всему хранилищу PDM, без записи в PDM.

Переиспользование чертежей развёрток

Сами развёртки в моделях обычно никто не хранит — плагин создаёт их при каждом прогоне. Зато чертёж _развертка.slddrw из прошлого проекта можно не трогать: он снова попадёт в альбом.

Уже есть _развертка.slddrw — в альбом без пересоздания Чертёжа нет — создаём лист (развёртку в модели — всё равно делаем)

Режимы на экране комплекта: только новые (по умолчанию), обновить отмеченные, пересоздать все.

Структура папок на «лазер»

Плагин создаёт папку даты и раскладывает DXF по толщине. PDF — в подпапку PDF.
