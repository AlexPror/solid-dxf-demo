Цех + лазер

Почему PDM обязателен

Без хранилища нельзя гарантировать версию и конфигурацию детали на лазере. Плагин не заменяет PDM — он берёт из vault правильные файлы. Результаты в PDM не сдаём (check-in не делаем).

Версия

Режем и кладём в альбом ту ревизию, что в vault.

Конфигурация

Исполнения -01, -02 — выбор на экране комплекта.

Только чтение

Поиск по шифру по всему vault, без записи в PDM.

Переиспользование развёрток

В пакете на 100–200 позиций многие детали уже встречались в прошлых проектах. Плагин не затирает чужую работу.

Уже есть _развертка.slddrw — в альбом Новая с гибами — создаём один раз

Режимы на экране комплекта: только новые (по умолчанию), обновить отмеченные, пересоздать все.

Структура папок на «лазер»

Плагин создаёт папку даты и раскладывает DXF по толщине. PDF — в подпапку PDF.

  • Ставка бутика / интегратора: 4–10 тыс. ₽/ч
  • Диапазон: 1,8–4,5 млн · черновик партнёра 3,4 млн

  • 2 500 ₽/ч — ставка solo/НПД на этом проекте (себестоимость в КП)
  • 4–7 тыс. ₽/ч — бутик C# + SOLIDWORKS API → 1,8–3,2 млн на это ТЗ
  • 6–10 тыс. ₽/ч — интеграторы PDM/SW → 2,5–4,5 млн

  • Weblancer — другой класс задач (макрос), не сравнивать с Docs v1

Калькулятор окупаемости

Три блока эффекта: отдел технологии (часы × ставка отдела) → риски на станке (срочный лазер, срывы комплекта — оценка) → срок изделия (сварка, покраска — без рублей, только пояснение). Стоимость внедрения — см. график выше.

Отдел технологии Часы отдела × ставка
Риски на станке Лазер раньше + меньше дыр в комплекте
Срок изделия Только если КД на критическом пути

Отдел технологии

Взносы — это ПФР, ФСС, ФОМС: сверх зарплаты работодатель платит ~30%. При окладе 90 000 ₽ место обходится ~117 000 ₽/мес. Для экономии часа отдела берём полную стоимость, иначе занижаем эффект.

Риски на станке (оценка)

Не «весь завод быстрее», а деньги там, где пакет КД был узким местом или ошибка всплыла бы на лазере/гибке. Если лазер всегда в очереди — срочный эффект ≈ 0, срывы комплекта могут остаться.

Внедрение

По умолчанию 930 000 ₽ — себестоимость (~46 дн. × 2 500 ₽/ч), уже минимум для исполнителя. Сравнение с рынком.

Влияет на «потолок цены» (экономия × срок), не на стоимость КП.
