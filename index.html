Демонстрация

Логика решения

По заявкам из 1С технологическое бюро на каждый проект собирает комплект для цеха: развёртки в формате DXF (складываются вручную в папку «лазер»), чертежи развёрток, чертежи деталей. В типичном проекте — 100–200 позиций, и цикл повторяется с каждой новой заявкой.

Задача — ускорить оформление, передачу и проверку комплекта документов для цеха: от заявки из 1С до готовой папки «лазер».

Бережная работа с PDM

Для конструкторского бюро и администраторов хранилища: надстройка не вносит изменений в PDM и работает только на просмотр — как технолог при ручном поиске модели.

  • Только чтение — поиск по шифру и открытие файла; без изъятия из хранилища и без правок карточек.
  • Обычный поиск в SOLIDWORKS PDM — тем же способом, что при работе технолога; к служебным данным на сервере надстройка не обращается.
  • Результаты — на папку «лазер» — готовые DXF, PDF и чертежи в PDM не размещаются.
  • Сначала тестовое хранилище — приёмка на учебной копии PDM или в согласованной папке, до подключения к рабочему хранилищу.
  • Без PDM можно работать — перечень, DXF и PDF сначала проверяются по согласованной папке; PDM подключают отдельным этапом.

Подробнее в приложении · зафиксировано в ТЗ-DOCS-01

Как делается сейчас и другие варианты
  1. Найти модели в PDM или в согласованной папке — по каждой строке перечня, нужное исполнение.
  2. Подготовить DXF для лазера: контур без фасок и резьб, раскладка по подпапкам толщины.
  3. Создать чертежи развёрток для гибочного станка — если деталь не плоский лист.
  4. Напечатать PDF из SOLIDWORKS — Save As PDF по каждому чертежу: модель и развёртка. Отдельные файлы, без общего альбома и оглавления.
  5. Разложить пакет вручную в папку «лазер» — сверить с Excel, разнести по толщине и порядку перед отдачей в цех.

PDM, чертежи развёрток, структура папок

Почему PDM обязателен

Без хранилища нельзя гарантировать версию и конфигурацию детали на лазере. Надстройка не заменяет PDM — она берёт из хранилища нужные файлы. Выпущенные материалы в PDM не размещаются.

Версия

Режем и кладём в альбом ту ревизию, что в хранилище.

Конфигурация

Исполнения -01, -02 — выбор на экране комплекта.

Только чтение

Поиск по шифру по всему хранилищу PDM, без записи в PDM.

Ограничения при работе с PDM

Опасение, что автоматизация повредит хранилище моделей, обосновано. В ТЗ-DOCS-01 закреплён щадящий режим: надстройка действует как технолог при просмотре файлов, без полномочий администратора PDM.

Что предусмотрено

  • Поиск детали по шифру в SOLIDWORKS PDM — так же, как при ручной работе технолога
  • Открытие модели в SOLIDWORKS для выпуска DXF и чертежа развёртки
  • Обращение к хранилищу по одной строке перечня — без массовой обработки
  • Выгрузка готовых файлов на сетевую папку «лазер»

Что не предусмотрено

  • Прямого доступа к служебным данным PDM на сервере
  • Изъятия файлов из хранилища и их возврата после обработки
  • Изменения карточек документов, версий, этапов согласования, прав пользователей
  • Создания папок, хранилищ и учётных записей
  • Размещения выпущенных DXF и PDF в PDM (в первой версии не предусмотрено)

Порядок внедрения: сначала проверка по согласованной папке (без PDM), затем тестовое хранилище PDM, и только после приёмки — рабочее хранилище в том же режиме «только чтение».

Переиспользование чертежей развёрток

Сами развёртки в моделях обычно никто не хранит — плагин создаёт их при каждом прогоне. Зато чертёж _развертка.slddrw из прошлого проекта можно не трогать: он снова попадёт в альбом.

Уже есть _развертка.slddrw — в альбом без пересоздания Чертёжа нет — создаём лист (развёртку в модели — всё равно делаем)

Режимы на экране комплекта: только новые (по умолчанию), обновить отмеченные, пересоздать все.
