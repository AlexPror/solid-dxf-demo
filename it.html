Границы взаимодействия

Что это

Модуль расширения SOLIDWORKS на рабочем месте. Не отдельный сервер и не доступ к служебной базе PDM.

Куда пишем

Только каталог «лазер». В SOLIDWORKS PDM готовые DXF и PDF не регистрируются.

Чего нет

Изъятие и возврат файлов в хранилище, изменение карточек документов.

Закрытый контур

Вынос моделей на съёмные носители не нужен. Работы — через удалённый рабочий стол или на площадке.

Перечень требований

Восемь условий для старта внедрения. Наведите на номер — краткий смысл.

01

Эталонное рабочее место

ПК или ВМ с SOLIDWORKS 2018 SP3 (x64) для установки и приёмки.

02

Удалённый рабочий стол

Доступ исполнителя; возможность закрыть SOLIDWORKS для обновления файлов модуля.

03

Права администратора

Один раз для установки «Комплект Docs». Выполняет системный администратор заказчика по инструкции (порядок).

04

Учётка PDM

Поиск и открытие моделей (уровень технолога), без администрирования хранилища.

05

Каталог «лазер»

Сетевой путь (UNC) с записью. Для пилота допустим отдельный каталог, например «лазер2».

06

Тестовое хранилище

Либо ограниченный пилот на рабочем хранилище только на чтение с выгрузкой в отдельный каталог.

07

Поле обозначения

Имя поля карточки PDM с шифром — уточняется на первом сеансе, если не задано заранее.

08

Журналы работ

Хранятся у заказчика; передача вовне — только по письменному согласованию.

Не требуется: создание отдельного хранилища «для подрядчика» силами исполнителя; открытие служебной базы PDM; вынос исходных кодов моделей за контур предприятия.

Этапы внедрения

A

Пилот

Тестовое хранилище или рабочее только на чтение · выгрузка в отдельный каталог · 15–20 позиций · акт A

B

Рабочее хранилище

Тот же режим только чтения на полном контуре PDM · акт B

C

Распространение

Копия %ProgramData%\SolidDxf\ на рабочие места · обучение · акт C

Обновление после доработки: закрыть SOLIDWORKS на эталоне, обновить bin; администратор копирует на остальные ПК. Повторная регистрация обычно не нужна.

Порядок установки «Комплект Docs»

Установку выполняет системный администратор заказчика по инструкции. Присутствие исполнителя не обязательно. Путь установки — только латиница.

Установочный комплект

payload\bin\

payload\clients\merkator\

install.ps1

→

На компьютере

C:\ProgramData\SolidDxf\bin\

C:\ProgramData\SolidDxf\clients\merkator\

регистрация в списке надстроек SOLIDWORKS

Включение в SOLIDWORKS

  1. 1 Завершить SOLIDWORKS и запустить снова
  2. 2 Инструменты → Надстройки (Tools → Add-Ins)
  3. 3 Включить SolidDxf (сеанс и при запуске)
  4. 4 Панель модуля справа в области задач
